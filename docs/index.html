¿Cómo Funciona?

Dos caminos complementarios para distinguir humanos de máquinas

🌐

Para Navegadores Humanos

  • Shell de atestación invisible al usuario
  • Proof-of-Work SHA-256 en segundo plano (~450ms)
  • Sesión con cookie HttpOnly firmada
  • Dwell time tracking para mutaciones POST
  • Acceso transparente tras verificación
⚡

Para Clientes No-Browser

  • Desafío HTTP 433 con cifrado multi-capa
  • Preguntas de razonamiento dinámicas
  • Detección por velocidad (<1500ms = bot)
  • Ofuscación: reverse → base64 → substitution
  • Bloqueo con código AI_AGENT_DETECTED
